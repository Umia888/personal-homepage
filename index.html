美团大学城美食地图

链接在美团内部平台 · 无法分享

目标用户：大学生。核心痛点是"吃什么"的决策困境。经用户观察，痛点根源包括： 平台认知负荷过高、商家供需不匹配、评价真实性存疑、行程时间成本、跨平台交互负担与预算约束。

  1. 个性化推荐：不粗暴减推送，而是按用户偏好优先级降序
  2. 即时评价 + 当地人评价：按 IP 划分本地/外地 → 提升可信度
  3. 好友 / 圈层美食地图共创：促进圈层信息流转与 GMV 转化
  4. 单项推荐 + 推荐理由：明星同款、减脂卡路里、时间预估
  5. 其他痛点：减脂餐一二级目录、高分/优惠标签、地图 API
03 常见问题 · About FAQ

你可能想问的那些事

你的背景和专业是什么？

本科 & 硕士都是法学方向，硕士是墨尔本大学 Master of Laws。 2022 年起接触 Vibe Coding，逐步从"法学生"过渡到"用 AI 做产品的人"， 现在在小红书做 AI 产品运营实习生。

为什么会从法学转到 AI 产品？

做法律 AI 项目的时候发现：真正把用户痛点变成产品的过程，比法条本身更让我兴奋。 我喜欢用户洞察，也喜欢用 Vibe Coding 直接把想法落地——这些放在一起，就是 AI 产品运营。

你最喜欢的作品是哪个？

#喜鹊谋杀案 和 #弗兰肯斯坦：前者达到过单条 19K+ 赞， 后者是我第一次做完整的拼贴叙事——不是最"专业"的作品，但是最像我的作品。

你在小红书具体做什么？

两条主线：一是点点生图，负责模型效果测评 + AI 模板方向设计 + 数据看板； 二是点点 Skills · Alex 星骰，负责 Knowledge 工程 + Skill 编写 + 回答质量优化。

模型测评你怎么做？

我会拆成几个维度：人脸一致性、模板契合度、身体比例、画质、稳定性， 按维度打分并归因（是 prompt 问题、模型能力问题、还是模板结构问题）， 再把结论反馈给模型与产品同学，用于判断"能不能上线 / 需不需要再练"。

什么是 Vibe Coding？你怎么理解？

Vibe Coding 就是——不排期，不等资源，把想法用 AI 直接推到可运行的原型。 对我来说它是"验证想法的最短路径"，而不是取代工程的手段。

做 Skill / Prompt 有什么心得？

三条：分块打标签 比 "写死大 prompt" 好用； QA 范例 比 "描述规则" 见效快；约束条件 是保底，不是主菜。

可以找你合作什么？

AI 产品咨询、模型测评方法、Prompt / Skill 工程、AIGC 内容制作、 以及"把一个想法快速做成能用的原型"这件事。

你的作品都是 100% AI 创作吗？

不是。每条内容我都会标注创作方式： #喜鹊谋杀案、#欢愉的艺术 是 100% AI； #弗兰肯斯坦 是 100% 拼贴； #锈湖 是 90% 拼贴 + 10% AI。

创作灵感一般来自哪？

艺术史（洛可可、启蒙）、影视文学（弗兰肯斯坦、锈湖）、社会议题（人造人 / 自然人的边界）。 我更喜欢用视觉去表达一种"感受"，而不是复刻一个"故事"。
