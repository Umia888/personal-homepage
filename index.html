美团大学城美食地图

链接在美团内部平台，无法分享

用户洞察与产品定位

目标用户限定为大学生，核心痛点是“吃什么”的决策困境。经用户观察，痛点根源在于： 平台认知负荷过高、商家供需不匹配、评价信息真实性存疑、行程规划的时间成本、 跨平台信息交互负担与预算约束。

核心功能设计

  • 个性化推荐餐厅：针对认知负荷过高（平台推荐信息冗余）。不粗暴减少推送数量以免损害选择自主性，而是依据用户历史偏好优化算法，按优先级降序排列。
  • 即时评价 + 当地人评价：针对信息真实性质疑（买评论、外地人推荐）。依据过去一年 IP 地址划分本地/外地用户，在原有“碎碎念”即时评价体系中补充当地人评价，提升评价价值。
  • 好友/圈层美食地图共创：针对跨平台信息交互负担（聚餐、好友推荐场景）。在“美食地图共创”基础上增加“同好”地图，在圈层内共创，促进信息流转与 GMV 转化。
  • 单项推荐 + 推荐理由：提升用户对“今天吃啥”结果的接受度。推荐结果下方附简短理由——明星同款贴明星海报、减脂给店铺均餐卡路里、时间维度给行程 + 等餐时间预估。
  • 其他痛点覆盖：供需不匹配、行程时间成本、预算约束，通过减脂餐一二级目录关联、高分/优惠餐厅一级目录标签与地图 API 调用来体现。

法律 AI 助手

AI 合同拟制助手 · 产学研合作 GitHub ↗

项目概述

产学研合作项目：合作企业提供技术平台，团队负责法律知识工程与产品验证。 产品定位为 BC 端相互导流的 AI 合同拟制助手，服务个人、律所及企业。（API 已过期，架构仍保留）

商务拓展与产学研合作

主动对接法律科技企业，赴深圳实地调研并完成合作谈判，签署技术授权书明确双方权责； 后自主运用 vibe coding 从零搭建网页端项目，并通过角色注入、CoT 与分块策略 （递归字符分块 + 语义分块）提升 LLM 回答专业性与 RAG 检索效率。

团队组建与项目管理

组建 10 人跨职能团队，与 50 人初创科技企业合作；制定 4 版商业计划书迭代计划， 统筹市场调研、产品设计、数据运营、财务建模全流程；通过甘特图与周会机制， 2 个月内完成从定题到省赛申报的全部工作。

法律知识库构建与模型调优

主导法律知识工程，整理并录入 300+ 份现行有效法律文件与案例，设计 200+ 个典型法律咨询场景进行模型测试。 通过“提问—评估—修改”闭环，将回答可用率从约 65% 提升至 87%（内部测试集）； 邀请用户试用，收集 1200+ 条有效反馈用于迭代。

商业计划与路演答辩

独立撰写 8 大模块商业计划书（项目背景、产品服务、市场分析、商业模式、运营计划、 财务计划、风险管理、里程碑），累计修改 4 版；主导校赛初赛、决赛、省赛申报及双创展览会全部路演， 制作 20+ 页 PPT 及答辩稿，现场应对评委提问。

项目成果

  • 产品完成真实场景验证，模型在法律咨询准确率、文书格式规范性上达成行业初期认可标准
  • 荣获第十四届“挑战杯”广东省省赛铜奖（获奖率低于 15%）、校内赛三等奖、校级双创展览会优秀奖
  • 积累 1200+ 条用户反馈与调优经验，为合作企业后续迭代提供数据支撑，项目进入孵化阶段

项目目标

Alex 大叔星骰是点点 Skills 中探索“博主内容 AI 化”的项目。目标是爬取博主语料与垂类知识， 让回答在保持专业性的同时，更像 Alex 本人。我主要负责 Knowledge 工程与 Skill 搭建 （项目无需交互效果 debug）。

主要工作

整理 Alex 的博主笔记与占星理论资料，搭建知识库结构，编写 Skill 规则，并对回答质量进行优化； 最终在 Cowork 平台发布，并积极寻找测评建议。

主要产出

  • 搭建了 Alex 项目的 Knowledge 体系
  • 将博主语料与占星理论区分、分块，并给各 chunk 打标签，避免风格混乱同时提升回复效率
  • 编写了主 Skill 与多个方向的子 Skill
  • 设置约束条件与 QA 范例优化回答质量，让回答更具体、准确，也更像博主本人

文风模拟器 · peter_tingle

彼得一激灵 GitHub · README ↗

它是什么

“灵光一现”写出来的工具。可以学习任何文章的写作风格与架构， 尤其擅长外语论文的表达方式与“祛 AI”，帮你更好地读文章、写文章。

它有什么用

  • 可作为 #skill，支持 Cursor、VS Code、Claude Code 直接调用
  • 提供可视化指南，帮助理解使用步骤（与 #obsidian 结合更高效）
  • 可叠加多个 API、文献管理器（如 Obsidian），按使用方式呈现不同程度能力
  • 让 AI “说人话、做人事”，真正给人增效而非添堵

经典使用场景

  • 学习雅思写作 / 托福写作
  • 学习论文写作风格与结构
  • 直接导出带格式的文章（内置论文格式，也可自行上传任意格式）
  • 了解大量文献的表达共同点与差异点
  • 整理文献观点，形成文献目录及原文定位清单

使用提醒

虽然能教你写外文文献，但 AI 率仍约 20%–30%（以英文论文为样本、非直译、两章文风调整测试）。 请把它作为学习文章架构与文风的工具，而非论文代写工具，不要过分依赖。

于我生命之碑长出的，是自我

在看过弗兰肯斯坦系列影视作品后，我最大的感触就是“我”之所以为“人”的独特性。

无论是自然人还是人造人，在社会议题下都会被统一地塑造为“社会人”，被成为有/无道德观念、群居属性、社会意识的人。

“社会人”是再造的，而非原生的。

无论是作为“人造人”还是“自然人”的我们，在独一无二的生命归途中，我们唯一能够确认的，即“我是我”。

即使现在的自己，否定了过去的自己；即使未来的自己，怨恨现在的自己；没关系，一切都没关系。

等到草木盘旋在砖石之上，等到尘土被风雨掀起、冲走，未来的你、现在的你、过去的你，会紧紧拥抱着彼此——只有自己会永远抓住自己。
